# متجر سند

موقع متجر إلكتروني لبيع الجوالات وبطاقات STC، مبني بـ Node.js و Express، مع لوحة تحكم لإدارة المنتجات والأسعار والصور والإعدادات.

## التشغيل المحلي

1. تأكد من تثبيت Node.js الإصدار 18 أو أحدث.

2. ثبّت الحزم:
   ```bash
   npm install
   ```

3. أنشئ ملف `.env` من النسخة النموذجية وعدّل القيم:
   ```bash
   cp .env.example .env
   ```
   ثم افتح `.env` وغيّر:
   - `ADMIN_USER` و `ADMIN_PASS` إلى بيانات دخول لوحة التحكم الخاصة بك
   - `SESSION_SECRET` إلى نص عشوائي طويل (لتشفير الجلسات)

4. شغّل الخادم:
   ```bash
   npm start
   ```
   أو أثناء التطوير (إعادة تشغيل تلقائي عند التعديل):
   ```bash
   npm run dev
   ```

5. افتح المتصفح على:
   - المتجر: http://localhost:3000
   - لوحة التحكم: http://localhost:3000/admin/login.html

## استخدام لوحة التحكم

- **المنتجات**: إضافة منتج جديد (جوال أو بطاقة STC) مع الاسم والسعر ووصف مختصر وصورة، أو تعديل/حذف منتج موجود.
- **الإعدادات**: تعديل اسم المتجر، رقم واتساب الذي يستقبل الطلبات، وعنوان/وصف الصفحة الرئيسية — دون الحاجة لتعديل الكود.

جميع البيانات تُخزَّن في ملفات JSON داخل مجلد `data/` (بدون قاعدة بيانات خارجية)، والصور تُحفظ في `public/uploads/`.

## قبل الرفع على استضافة فعلية

- **غيّر** `ADMIN_PASS` و `SESSION_SECRET` إلى قيم قوية وفريدة، ولا ترفع ملف `.env` إلى أي مستودع عام (موجود بالفعل ضمن `.gitignore`).
- فعّل HTTPS على الاستضافة، وأضف `cookie: { secure: true }` في إعداد الجلسة داخل `server.js` بعد تفعيل HTTPS.
- فكّر في أخذ نسخة احتياطية دورية من مجلد `data/` و `public/uploads/` لأن البيانات مخزَّنة في ملفات محلية.
- إن كان حجم الكتالوج كبيرًا مستقبلًا (مئات المنتجات)، يُفضَّل الانتقال لاحقًا من ملفات JSON إلى قاعدة بيانات حقيقية (مثل SQLite أو PostgreSQL).
- اسم وشعار "STC" علامة تجارية مملوكة لشركة الاتصالات السعودية؛ استخدامها هنا كوصف عام لمنتج مقبول تجاريًا طالما لا يوحي الموقع بأنك وكيل رسمي دون أن تكون كذلك فعليًا.

## هيكل المشروع

```
sanad-store/
├── server.js              # نقطة تشغيل الخادم
├── src/
│   ├── data.js             # قراءة/كتابة ملفات JSON
│   ├── middleware/auth.js  # حماية مسارات لوحة التحكم
│   └── routes/
│       ├── products.js     # API عام (المتجر)
│       └── admin.js        # API محمي (لوحة التحكم)
├── data/
│   ├── products.json
│   └── settings.json
└── public/
    ├── index.html           # واجهة المتجر
    ├── css/ js/
    ├── uploads/             # صور المنتجات المرفوعة
    └── admin/               # لوحة التحكم
```
